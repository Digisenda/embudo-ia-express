# Imágenes

Esta carpeta contiene las imágenes utilizadas en el proyecto.

## Estructura recomendada:

```
/public/images/
├── hero/           # Imágenes de fondo para Hero
├── logos/          # Logos de clientes
├── testimonials/   # Fotos de personas para testimonios
├── features/       # Iconos o imágenes para features
└── og/            # Imágenes para Open Graph (redes sociales)
```

## Imágenes recomendadas:

1. **Hero Background** (1920x1080px o superior)
   - Para usar en `hero.backgroundImage`
   
2. **Logo del negocio** (PNG transparente, 500x500px)
   - Para usar en `logo`

3. **Testimonial avatars** (Cuadradas, 200x200px)
   - Para usar en testimonios

4. **OG Image** (1200x630px)
   - Para usar en `seo.ogImage`

## Fuentes de imágenes gratuitas:

- **Unsplash**: https://unsplash.com
- **Pexels**: https://pexels.com
- **Pixabay**: https://pixabay.com

## Nota importante:

Las imágenes deben optimizarse antes de subirlas:
- Usar formatos modernos (WebP, AVIF)
- Comprimir para web
- Tamaños apropiados para cada uso
